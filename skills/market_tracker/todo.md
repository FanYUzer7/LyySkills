# Market Tracker Skill - 功能增强 TODO

> Code Review 后的功能完备性建议，按优先级排序

## 高优先级

### 1. 离线测试模式 (`--test` / `--dry-run`)
- **现状**: `test_data/sample_kline.json` 已存在但无 CLI 入口使用
- **问题**: 无网络环境下无法验证分析逻辑，agent 首次使用时也无法快速验证安装正确性
- **建议**: 新增 `analyze --code 600519 --type stock --test` 模式，从 test_data 加载数据并跳过网络请求
- **工作量**: 小（在 tracker.py 加载测试数据分支即可）

### 2. 依赖检查/自动安装
- **现状**: 依赖不满足时报 ImportError，agent 需自行判断原因
- **建议**: 在 `__main__.py` 入口增加依赖检查，缺失时打印 `pip install -r requirements.txt` 提示
- **工作量**: 小

### 3. 错误处理增强
- **现状**: `get_realtime_quote` 返回 None 时，`analyze()` 中 `quote` 为 None 但格式化报告中 `quote.get(...)` 不会崩溃（因有 `or {}`）。但 AKShare 网络请求失败时，异常信息不够用户友好
- **建议**: 统一错误码体系，区分"网络错误"/"API变更"/"代码无效"/"数据不足"等场景
- **工作量**: 中

## 中优先级

### 4. 模拟实盘回测
- **现状**: 有完整的技术指标和决策引擎，但无法验证信号质量
- **建议**: 新增 `backtest` 命令，基于历史K线回放决策信号，统计胜率/盈亏比/最大回撤
  - 可复用 `InvestmentDecision.analyze()` 对历史每个交易日生成信号
  - 简单的固定仓位回测即可（如信号买入 → 下一日开盘价成交）
  - 输出: 总收益率、年化收益、最大回撤、胜率、盈亏比
- **工作量**: 中（核心逻辑 ~200 行）
- **参考**: AlphaGPT 项目中 `model_core/backtest.py` 已有回测框架可借鉴

### 5. 多周期分析
- **现状**: 仅支持日线级别
- **建议**: 新增 `--period weekly/monthly/60min` 参数
  - AKShare 的 `stock_zh_a_hist` 本身支持 `period` 参数
  - 多周期共振信号可提升决策可信度
- **工作量**: 中

### 6. 基于 ATR 的动态止损/止盈建议
- **现状**: `_support_resistance` 仅取近20日高低点
- **建议**: 基于 ATR 计算动态止损位（如 `close - 2*ATR`），止盈位（如 `close + 3*ATR`）
  - 更符合量化交易实践
  - 可根据波动率自适应调整
- **工作量**: 小

### 7. 信号变化检测 (monitor 增强)
- **现状**: monitor 模式每次全量输出所有标的报告
- **建议**: 对比上次分析结果，仅在信号发生实质性变化时高亮提醒
  - 如"从持有变为买入"、"RSI 突破超买区"等
  - 可将上次结果序列化到 SQLite 或内存中
- **工作量**: 中
