# 金融市场资讯分析 Skill

## 功能概述

这是一个用于实时获取和分析中国金融市场资讯的skill。它能够：

1. **实时资讯获取** - 使用minimax MCP搜索A股、期货、黄金等中国金融市场的最新资讯
2. **智能分析** - 对收集的资讯进行情绪分析、关键事件提取、板块表现分析
3. **综合报告** - 生成带有事实依据的投资分析参考

## 触发条件

当用户请求以下内容时触发此skill：
- 获取金融市场资讯
- 分析A股/期货/黄金市场
- 了解今日市场行情
- 获取市场快讯/分析报告

## 执行步骤

### Step 1: 搜索资讯

使用 `mcp__MiniMax__web_search` 工具搜索金融市场资讯。

**A股市场关键词**：
- "A股 今日行情"、"A股 市场分析"、"A股 板块轮动 今日"
- "创业板 科创板 今日行情"
- "A股 今日 快讯"

**期货市场关键词**：
- "期货 市场行情 今日"
- "大宗商品 期货 原油"
- "PTA 燃料油 期货走势"

**黄金市场关键词**：
- "黄金 沪金 行情 今日"
- "金银 期货 走势"
- "现货黄金 期货黄金"

**综合分析关键词**：
- "金融 市场 快讯 今日"
- "宏观经济 市场 分析"
- "A股 机构 观点"

### Step 2: 提取搜索结果

从搜索结果中提取 `organic` 字段的内容，构建JSON格式：
```json
{
  "organic": [
    {
      "title": "新闻标题",
      "link": "链接地址",
      "snippet": "新闻摘要",
      "date": "发布日期"
    }
  ]
}
```

### Step 3: 调用分析器

将搜索结果传递给分析脚本进行分析：

```bash
# 方法1: 通过stdin传递JSON数据
echo '{"organic": [...]}' | ~/miniconda3/envs/py311/bin/python /home/youya/workspace/MySkills/skills/finance_news/analyzer.py

# 方法2: 通过文件传递
# 先将JSON保存到临时文件，然后调用分析器
```

### Step 4: 输出报告

分析器会输出完整的分析报告，包含：
- 市场情绪分析
- 关键事件摘要
- 板块表现分析
- 分析总结

## 输出格式

```
============================================================
📊 金融市场资讯分析报告
📅 生成时间: YYYY-MM-DD HH:MM:SS
📰 资讯来源: X 条
============================================================

🌡️ 【市场情绪分析】
   整体情绪: X (置信度: XX%)

📌 【关键事件摘要】
   1. [事件类型] 事件标题

   基于事实的分析结论

⚠️ 【风险提示】
   本分析基于公开资讯，仅供参考，不构成投资建议。

```
