# Market Tracker 量化分析技术文档

## 一、采用的指标体系

该系统采用**四大类技术指标**，覆盖趋势、动量、成交量、波动率：

| 类别 | 指标 | 说明 |
|------|------|------|
| **趋势类** | SMA、EMA、MACD、布林带、ADX | 判断市场方向 |
| **动量类** | RSI、KDJ、CCl、ROC | 衡量价格动能 |
| **成交量类** | OBV、MFI、成交量均线、VWAP | 量价配合分析 |
| **波动率类** | ATR、历史波动率、最大回撤 | 风险控制 |

## 三、核心指标含义

### 3.1 趋势类指标

| 指标 | 计算公式 | 意义 |
|------|----------|------|
| **SMA/EMA** | 简单/指数移动平均 | 均线多头排列看多，空头排列看空 |
| **MACD** | DIF=EMA12-EMA26, DEA=EMA(DIF,9), Hist=2×(DIF-DEA) | 金叉看多，死叉看空，零轴上方偏多 |
| **布林带** | 中轨=SMA20, 上/下轨=中轨±2σ | 突破上轨预警回调，跌破下轨关注反弹 |
| **ADX** | 基于±DI计算趋势强度 | ADX>25有有效趋势，<25为震荡市 |

### 3.2 动量类指标

| 指标 | 计算公式 | 意义 |
|------|----------|------|
| **RSI** | 100 - 100/(1+RS), RS=avg_gain/avg_loss | >70超买预警回调，<30超卖关注反弹 |
| **KDJ** | RSV→K→D→J (J=3K-2D) | J>100超买极端，J<0超卖极端，金叉买入 |
| **CCI** | (TP-SMA(TP))/(0.015×MD) | >100强势，<-100弱势 |
| **ROC** | (Close-Close_n)/Close_n×100% | 价格变化率，正值看多 |

### 3.3 成交量类指标

| 指标 | 计算公式 | 意义 |
|------|----------|------|
| **OBV** | 涨日+Vol，跌日-Vol，累积 | 能量潮，与价格背离预警 |
| **MFI** | 资金流量指数(带量的RSI) | >80超买，<20超卖 |
| **VWAP** | Σ(TP×Vol)/ΣVol | 成本均线，低于看多 |

### 3.4 波动率类指标

| 指标 | 计算公式 | 意义 |
|------|----------|------|
| **ATR** | 真波幅Wilder平滑 | 动态止损：价格-2×ATR |
| **历史波动率** | Std(Log Returns)×√252 | 年化波动率 |
| **最大回撤** | Max(Peak-Trough)/Peak | 风险度量 |

## 四、量化因子评分体系

### 4.1 动量因子

- **计算**: 多周期收益率 (20日、60日、120日) 的标准化加权
- **意义**: 反映价格趋势强度

### 4.2 波动因子

- **计算**: 历史波动率 + 最大回撤的组合
- **意义**: 波动率越低、回撤越小，得分越高

### 4.3 量价因子

- **计算**: 量价相关性 + 近期量能趋势
- **意义**: 放量上涨为正分，缩量下跌为负分

## 五、可补充的其他指标

| 类别 | 指标 | 建议 |
|------|------|------|
| **趋势** | SuperTrend、SAR、Ichimoku | 增强趋势判断 |
| **动量** | Stochastic、Williams %R、MOM | 多维度动能验证 |
| **量价** | Volume Profile、Accumulation/Distribution | 主力资金识别 |
| **波动** | Keltner Channel、Donchian Channel | 突破交易系统 |
| **基本面** | PE、PB、ROE (如适用) | 价值投资筛选 |
| **市场广度** | 上涨下跌家数、新高新低 | 大盘环境判断 |

### 建议补充的实用组合

1. **趋势确认**: SuperTrend + ADX 双重确认
2. **择时信号**: Stochastic + RSI 组合过滤
3. **突破交易**: Bollinger + Volume 放量确认
4. **风控增强**: Keltner Channel 替代布林带
